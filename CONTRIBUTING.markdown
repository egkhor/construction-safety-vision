# Contributing to Construction Safety Vision AI

We’re excited to build a community-driven AI for construction safety! Here’s how you can contribute:

## Ways to Contribute
- **Images**: Share labeled construction site images (e.g., workers without helmets, unsafe scaffolding). Use anonymized data and submit via GitHub Issues or a secure form (TBD).
- **Models**: Train vision models (e.g., YOLOv8, MobileNet) and convert to CoreML. Share scripts in `src/`.
- **Code**: Add SwiftUI code for iOS apps to display hazard alerts.
- **Features**: Suggest new hazard types or metadata fields in `generate_synthetic_images.py`.
- **Feedback**: Report bugs or propose improvements via GitHub Issues.

## How to Contribute
1. Fork the repository: `https://github.com/egkhor/construction-safety-vision`.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Commit changes: `git commit -m "Add your feature"`.
4. Push and open a pull request.
5. Join Discussions for ideas: [GitHub Discussions](https://github.com/egkhor/construction-safety-vision/discussions).

## Guidelines
- Ensure code is well-documented.
- Use anonymized data to protect privacy.
- Test scripts locally before submitting.

Thanks for helping make construction sites safer! 🦺
